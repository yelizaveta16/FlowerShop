# Функциональные требования к проекту Flower Shop

## 1. Общая информация
Flower Shop — веб-приложение интернет-магазина цветов. Система позволяет просматривать каталог, выбирать товары, формировать корзину и оформлять заказы.

## 2. Роли
- **Гость:** просматривает каталог, ищет товары и регистрируется.
- **Покупатель:** использует корзину, оформляет заказ и просматривает свои заказы.
- **Администратор:** управляет товарами, категориями и заказами.

## 3. Функциональные требования

### Главная страница и каталог
- **FR-01.** Система отображает главную страницу магазина.
- **FR-02.** Система отображает каталог доступных товаров.
- **FR-03.** Карточка товара содержит название, изображение, описание, цену и наличие.
- **FR-04.** Пользователь может открыть подробную информацию о товаре.
- **FR-05.** Пользователь может искать товары по названию.
- **FR-06.** Пользователь может фильтровать товары по категории.

### Учётная запись
- **FR-07.** Система предоставляет регистрацию пользователя.
- **FR-08.** Система проверяет корректность данных и уникальность электронной почты.
- **FR-09.** Система предоставляет вход и выход из аккаунта.
- **FR-10.** Покупатель имеет доступ к личному кабинету и истории заказов.

### Корзина и заказы
- **FR-11.** Покупатель может добавлять товары в корзину.
- **FR-12.** Покупатель может изменять количество и удалять товары из корзины.
- **FR-13.** Система рассчитывает итоговую стоимость корзины.
- **FR-14.** Система проверяет наличие товара перед оформлением.
- **FR-15.** Покупатель указывает контактные данные и способ получения заказа.
- **FR-16.** Система сохраняет заказ и его позиции в базе данных.
- **FR-17.** Заказ получает уникальный номер и статус «Новый».

### Администрирование
- **FR-18.** Администратор может добавлять, изменять и удалять товары.
- **FR-19.** Администратор может управлять категориями.
- **FR-20.** Администратор может просматривать заказы и изменять их статусы.

## 4. Основные сценарии
### Просмотр каталога
1. Пользователь открывает сайт.
2. Переходит в каталог.
3. Использует поиск или фильтр.
4. Выбирает товар и изучает его описание.

### Оформление заказа
1. Покупатель добавляет товары в корзину.
2. Проверяет количество и сумму.
3. Указывает имя, электронную почту и телефон.
4. Выбирает доставку или самовывоз.
5. Подтверждает заказ.
6. Сервер проверяет наличие и цены.
7. Система сохраняет заказ и позиции в PostgreSQL.
8. Покупатель получает номер заказа.

## 5. Критерии приёмки
- Каталог загружается из базы данных.
- Поиск и фильтр изменяют список товаров.
- Корзина позволяет менять количество и удалять позиции.
- Итоговая стоимость пересчитывается.
- Заказ сохраняется в базе данных.
- При недостатке остатка сервер отклоняет заказ.

## 6. Заключение
Требования определяют поведение Flower Shop и служат основой для реализации, тестирования и дальнейшего расширения приложения.
