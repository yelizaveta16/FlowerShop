# Проверка проекта

Ручная проверка:
1. Откройте `/api/health` — должен вернуться `{"status":"OK","storage":"JSON files","database":false}`.
2. Проверьте каталог, поиск и фильтр.
3. Зарегистрируйте нового пользователя.
4. Выйдите и войдите с теми же данными.
5. Добавьте товар в корзину и оформите тестовый заказ.
6. Проверьте, что в `data/orders.json` появился заказ, а остаток в `data/products.json` уменьшился.

Для промышленного проекта следует добавить автоматизированные тесты API.
