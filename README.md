# Flower Shop — версия без PostgreSQL

Учебный интернет-магазин цветов. Данные хранятся в JSON-файлах внутри папки `data`. PostgreSQL, MySQL и другие СУБД не нужны.

## Возможности
- адаптивный сайт с каталогом цветов;
- поиск и фильтр по категориям;
- корзина в `localStorage` браузера;
- оформление заказов;
- регистрация и вход;
- пароли хранятся в виде bcrypt-хеша;
- JWT-токен для авторизации;
- пользователи в `data/users.json`;
- заказы в `data/orders.json`;
- товары и остатки в `data/products.json`.

## Запуск на Windows
1. Установите Node.js (LTS).
2. Откройте папку проекта в VS Code.
3. Откройте терминал: **Терминал → Создать терминал**.
4. Выполните:
   ```powershell
   npm install
   npm run build
   npm run dev
   ```
5. Откройте в браузере `http://localhost:3000`.

Если появится сообщение, что порт занят, остановите другой запущенный сервер сочетанием `Ctrl+C` или измените `PORT` в `.env`.

## Регистрация и вход
1. Нажмите «Войти» в верхней части сайта.
2. Перейдите на вкладку «Регистрация».
3. Укажите имя, email и пароль от 8 символов.
4. После регистрации пользователь автоматически войдёт в аккаунт.
5. Нажатие на приветствие с именем пользователя выполняет выход.

## Где хранятся данные
- `data/products.json` — каталог и остатки товаров;
- `data/users.json` — зарегистрированные пользователи (пароли в виде bcrypt-хешей);
- `data/orders.json` — оформленные заказы.

Не удаляйте эти файлы, если хотите сохранить данные. Перед изменениями делайте резервную копию папки `data`.

## API
| Метод | URL | Описание |
|---|---|---|
| GET | `/api/health` | Проверка сервера |
| GET | `/api/categories` | Категории |
| GET | `/api/products` | Каталог; параметры `search`, `category` |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET | `/api/auth/me` | Профиль с Bearer JWT |
| POST | `/api/orders` | Оформление заказа |

## Важные ограничения
Это учебный локальный проект. JSON-файлы не подходят для большого числа одновременных пользователей: при одновременной записи возможны конфликты. JWT-токен хранится в `localStorage`, что допустимо для демонстрационного проекта, но для реального магазина нужна более строгая защита. Не размещайте публично реальные персональные данные и не используйте этот проект для реальных платежей.
